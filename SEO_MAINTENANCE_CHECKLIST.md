# SEO Maintenance Checklist

## Weekly Tasks
- [ ] Check Core Web Vitals in PageSpeed Insights
- [ ] Monitor Google Search Console for crawl errors
- [ ] Review click-through rates and impressions
- [ ] Check for broken internal links
- [ ] Monitor analytics for traffic anomalies

## Monthly Tasks
- [ ] Regenerate XML sitemaps
- [ ] Update robots.txt if needed
- [ ] Review and optimize meta descriptions
- [ ] Check heading hierarchy on all pages
- [ ] Verify HTTPS/SSL certificate validity
- [ ] Analyze competitor SEO changes
- [ ] Review keyword rankings

## Quarterly Tasks
- [ ] Comprehensive content audit
- [ ] Technical SEO audit
- [ ] Backlink analysis
- [ ] Update structured data schemas
- [ ] Review and optimize images
- [ ] Check for duplicate content
- [ ] Mobile usability assessment

## Annual Tasks
- [ ] Full website SEO audit
- [ ] Update SEO strategy based on analytics
- [ ] Review and update all meta tags
- [ ] Conduct competitive analysis
- [ ] Plan content calendar
- [ ] Review and update internal linking strategy
- [ ] Update robots.txt and sitemaps

## Monitoring Tools
- Google Search Console
- Google Analytics 4
- PageSpeed Insights
- Bing Webmaster Tools
- Schema.org Validator
- Mobile-Friendly Test
